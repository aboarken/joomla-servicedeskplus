# com_servicedeskplus 1.34.0

Second audit round. Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes and no settings to change.

This version was installed, upgraded from 1.33.0, tested and uninstalled in a real Joomla 6.2.1 site with PostgreSQL, against a stand-in ServiceDesk Plus server.

## Security
- Every administrator page and task needs *Configure*, checked in one place.
- The same new-request form sent twice at the same moment creates one request.
- API answers are limited to 16 MB (attachment downloads: 32 MB).

## Fixed
- A deleted Joomla account no longer blocks its ServiceDesk Plus user for a new account.

## Changed
- Announcements load faster when some are restricted to groups.
- The portal works under a strict Content-Security-Policy (no `style` attributes).
- Disabled pagination links can't be reached with the keyboard.

## For developers
- 55 end-to-end checks (`tests/EndToEnd`) and 83 unit tests.
