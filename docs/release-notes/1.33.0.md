# com_servicedeskplus 1.33.0

Technical and security audit. Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). One database update: a new index on the audit table (applied automatically).

## Security
- A portal user linked to the API technician's ServiceDesk Plus user sees and decides no approvals, however the link was made.
- Changing *Show approvals for* or the API technician e-mail clears cached approval lists.
- Ids with leading zeros are refused; attachment downloads are limited to 200 per user and hour.
- File names, approval comments, the Find Endpoints report and the request form's saved text are cleaned further.

## Faster and lighter
- Request pages read their conversation and approvals in parallel.
- A timed-out read is not repeated; a failed identity re-check waits 15 minutes before the next try.
- Page reads are logged only with Joomla's *Debug System* on; old audit rows (except decisions) are removed after a year.

## Accessibility and Arabic
- Better contrast and focus outlines, screen-reader names for the priority bars, right-to-left layout fixes.

## For developers
- 76 unit tests (PHPUnit) run in the release workflow.
