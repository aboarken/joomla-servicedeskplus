# com_servicedeskplus 1.31.6

Security hardening. Update from **System → Update → Extensions**, or install `com_servicedeskplus.zip` (attached below). No database changes and no settings to change.

## Security
- **The API technician can't be linked to a portal user:** matching by e-mail skips it, User Mappings refuses it, and an existing link to it is suspended.
- **"Show approvals for" is enforced:** a record type that is switched off can't be opened, downloaded from or decided by typing its address.
- **Approval comments are sent as text:** `<`, `>` and `&` can't become markup where ServiceDesk Plus shows the comment.
- **Answers from ServiceDesk Plus are limited to 32 MB**, so a wrong or hijacked server can't fill PHP's memory.
- **Attachment previews:** previewed PDFs can't submit forms, and files aren't shared with other sites.
- An internal helper of the approval controller can no longer be called from a URL.

## Release process
- The build has read access only; publishing runs separately, only from `main`, and never replaces an existing release unless asked.
